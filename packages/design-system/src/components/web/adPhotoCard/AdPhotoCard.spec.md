## 목적과 범위

- 피드의 광고(BUNCH SPOT) 카드. `FeedBundleCard`의 사진과 같은 4:5·모서리 24.
- 기본: 배경 사진, 위쪽 로고·배지·홍보 문구·`PlacePickButton`(폭 88)·더보기(⋯), 아래쪽 장소 이름·소개·위치·태그 칩.
- 숨김(`state="hidden"`): 회색 카드 가운데 체크 아이콘(36)과 「장소를 숨김 처리 했어요」. 체크는 처음 그릴 때 한 번 커졌다 돌아온다.
- Figma 설명대로 기존 `Ad Card`(`4137:109349`)와는 별개다.
- 담기·취소, 더보기 메뉴·숨기기 확인 시트, 새로고침 뒤 카드를 빼는 처리는 호출자가 한다. 외부 링크 동작은 Figma·명세에 없어 사진은 누를 수 없다.

## Public API

- 공통: `title`(필수), native `<article>` 속성.
- 기본: `imageSrc`(필수)·`imageAlt`, `logoSrc`, `badge`(기본 「BUNCH SPOT」), `tagline`(필수), `description`, `location`, `tags`, `picked`·`onPick`, `onMore`·`moreLabel`, `titleAs`(기본 `h3`).
- 숨김: `state="hidden"`, `hiddenLabel`.

## 접근성

- `article` 이름은 「광고 {장소 이름}」.
- 더보기 이름 기본값은 「{장소 이름} 광고 더보기」. 아이콘 20, 누르는 영역 40. 초점 테두리는 사진 위라 흰색(`border-inversed`). 콕하기와의 간격 12에서 누르는 영역이 2px 남으므로 간격을 줄이지 않는다.
- 콕하기 버튼에는 장소 이름을 설명(`aria-describedby`)으로 붙여 피드의 여러 광고를 구분한다.
- 위치 앞에 「위치」를 낭독용으로 붙이고, 태그는 목록(`ul`)으로 읽힌다.
- 알림 영역(`role="status"`)은 기본 상태부터 빈 채로 두고, 숨김으로 바뀌면 같은 영역에 안내 글자를 채워 낭독되게 한다.
- 숨기기로 더보기 버튼이 사라지면 초점이 갈 곳이 없어진다. 숨김 카드는 `tabIndex={-1}`이라 호출자가 이 카드(또는 다음 항목)로 초점을 옮긴다.
- 사진은 기본이 장식(빈 `alt`)이다. 장소 정보가 글자로 모두 있기 때문이며, 사진이 따로 정보를 담으면 `imageAlt`를 넘긴다.
- 체크 모션은 동작 줄이기 설정이면 끈다.

## Styling과 의존성

- 사진을 받기 전이나 받지 못했을 때도 흰 글자가 보이게 카드 바탕은 `surface-inversed`(어두운 회색)다(Figma에 없음).
- 그라데이션은 Figma 값을 그대로 썼다(위 검정 35%→0 높이 112, 아래 60%→50%→8%→0 높이 136, 토큰 없음).
- 배지는 `primitive-white-alpha-20` 배경에 흰 글자, 태그는 `ColorBadge` gray(md, 좌우 6·위아래 2).
- 숨김 모션: 0.567s 동안 크기 0 → 1.2 → 1(`cubic-bezier(0.55,0.06,0.36,1)`), 투명도는 앞 0.233s에 0 → 1. Figma는 2초 반복 미리보기라 한 번만 재생한다.
- Storybook: `Default`(콕하기를 누르면 바뀜), `Hidden`.

## 확인할 항목

- 사진을 눌렀을 때 외부 링크로 갈지(Figma·명세에 없음).
- 흰 글자·더보기 아이콘·흰 초점 테두리 대비는 밝은 사진에서 부족할 수 있다(위 그라데이션이 35%로 약함, Figma 값). 밝은 사진으로 측정해 디자이너와 확인한다.
- 숨김 안내 글자 `text-quinary`(#BCBEC2)는 `surface-secondary`(#F5F5F5) 위에서 약 1.7:1이다(Figma 값, 디자이너 확인).
- 홍보 문구는 한 줄 말줄임이라 긴 문구는 잘린다(Figma 값).
- 태그가 많으면 줄바꿈한다. Figma는 한 줄이라 넘칠 때 모양은 정한 값이다.
