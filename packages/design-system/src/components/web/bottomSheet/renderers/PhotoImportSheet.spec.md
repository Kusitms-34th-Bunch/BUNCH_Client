## 목적과 범위

- 번들 사진 캡션 화면의 「+ 사진 추가」로 여는 가져오기 출처 선택 시트. 제목 「어디서 사진을 가져올까요?」와 「번치 사진함에서 가져오기」·「내 갤러리에서 가져오기」 카드.
- 사진 선택 화면으로 이동, 기기 사진 연결, 사진함 가득 참 안내는 번들 feature가 맡는다.

## Public API

- `open`, `onOpenChange`, `onOpenChangeComplete`: `BottomSheet.Root`와 같음.
- `onSelectBunchBox()`, `onSelectGallery()`: 카드를 누르면 호출. 시트는 스스로 닫지 않는다.
- 제목과 카드 문구는 Figma 고정 문구라 컴포넌트가 가진다.

## 상태와 동작

- 바깥 터치·끌기·ESC·숨긴 닫기 버튼으로 닫는다(화면설계서 2번: 바깥 선택 또는 아래로 스와이프 시 닫힘).
- 호출자는 카드 콜백에서 먼저 `open`을 `false`로 바꾼 뒤 이동하거나 기기 사진을 연다. 연타로 콜백이 두 번 불리는 것도 호출자가 막는다.

## 접근성

- 제목이 시트 이름. 카드는 버튼(제목이 이름, 설명이 설명).
- 화면에 닫기 버튼이 없어 키보드 초점 때만 보이는 닫기 버튼을 둔다(첫 초점 위치).
