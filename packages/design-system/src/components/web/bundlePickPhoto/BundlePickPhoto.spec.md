- 이슈: #267

## 목적과 범위

- 대표 사진 투표(번들 픽) 화면에서 한 장씩 넘겨 보는 사진 카드. 사진만 있고 삭제·페이지 표시 같은 얹는 요소는 없다.
- 사진 목록을 넘기는 동작, 가운데가 아닌 사진을 흐리게 하는 상태는 호출하는 쪽이 `className`으로 정한다.

## Public API

- `src`, `alt`(필수): 사진 주소와 설명(꾸미는 사진이면 빈 문자열)
- native `div` 속성과 `className`(틀에 적용)
