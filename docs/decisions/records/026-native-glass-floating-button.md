# 026: iOS 26 쉘의 플로팅 버튼은 네이티브 Liquid Glass로 그린다

- 상태: proposed
- 기록일: 2026-11-15
- 구현 상태(2026-11-15 확인): 번치 홈 「번들 만들기」와 사진함 「사진 올리기」·「메뉴 열기」에 구현됨. iOS 시뮬레이터(iPhone 17 Pro, iOS 26.5)에서 두 탭의 버튼이 유리로 그려지는 것과 누름·선택 모드·시트 동작을 확인했다. 실기기, 렌즈 효과의 실제 터치, VoiceOver는 확인하지 못했다.

## 배경

iOS 26 앱은 화면에 떠 있는 버튼도 Liquid Glass로 그린다. 시스템 탭 바(012)는 이미 유리인데, 그 위의 플로팅 버튼은 웹 `FloatingButton`(흰 원과 그림자)이라 둘의 질감이 달랐다. 웹 CSS로는 뒤를 흐리는 효과까지만 낼 수 있고 굴절·렌즈는 낼 수 없다(011).

## 결정

- iOS 26 이상 쉘의 탭 화면에서는 플로팅 버튼을 쉘이 `expo-glass-effect`의 `GlassView`(`regular`, 누름 반응 켬)로 탭 WebView 위에 그린다. 웹 버튼은 그리지 않는다.
- iOS 26 미만·안드로이드·브라우저, 그리고 이 메서드가 없는 이전 쉘은 웹 버튼을 그대로 쓴다.
- 버튼의 아이콘·접근성 이름·누를 수 없음·메뉴 열림은 웹이 정하고 bridge `setNativeFloatingButton`으로 보낸다. 눌림은 쉘이 `nativeFloatingButtonPress` 이벤트로 돌려준다.
- 버튼은 탭마다 하나다. 탭 WebView가 여러 개라서 쉘은 탭 ID별로 버튼을 저장하고 그 탭 화면에만 그린다.
- 시트·대화상자가 열린 동안, 화면 전체를 덮는 로딩 동안, 그리고 화면을 떠나면 웹이 버튼을 지운다. 네이티브 버튼은 WebView 위에 있어 웹 시트보다 위에 보이기 때문이다.
- 같은 이유로 웹 토스트가 버튼 뒤에 깔려, 버튼이 떠 있는 동안의 아래쪽 토스트는 쉘이 네이티브로 그린다(030, 2026-11-22).

## 비교한 대안

- **웹 CSS 유리(`backdrop-filter`)**: 모든 플랫폼에서 같지만 굴절·누름 렌즈가 없어 시스템 탭 바와 질감이 다르다.
- **`glassEffectStyle: 'clear'`**: 더 투명하지만 흰 배경에서는 원이 사라지고 「+」 선만 남아 버튼으로 보이지 않았다(시뮬레이터 확인). `regular`는 뒤 밝기에 맞춰 대비를 잡는다.
- **버튼 뒤가 사진일 때만 `clear`로 바꾸기**: 스크롤마다 버튼 밑이 사진인지 웹이 계산해 보내야 해서 bridge 호출이 많고 얻는 차이가 작다.
- **SF Symbol 아이콘**: 시스템 아이콘이라 디자인 시스템과 모양이 다르다. 탭 아이콘처럼 디자인 시스템 SVG(`line-add`·`line-dots`, Large 24px)를 1x·2x·3x PNG로 옮기고 `tintColor`로 색을 칠한다(`assets/floating-icons/`).

## 결과

- 쉘이 WebView 밖에 네이티브 UI를 하나 더 갖는다. 탭 바(012) 다음 두 번째 예외다.
- 쉘은 탭 WebView에 자기 탭 ID를 sessionStorage(`bunch-shell-tab`)로 알려 준다. 다른 탭 WebView가 같은 경로(예: `/bunch`)를 열어도 그 탭의 버튼을 덮어쓰거나 지우지 않는다. `<html>` 속성은 React hydration이 지워서 쓰지 않았다.
- 웹 버튼과 다른 점이 있다.
  - 「+」↔「⋯」 아이콘은 크로스페이드 없이 바로 바뀐다.
  - 선택 모드에서 탭 바가 숨을 때 버튼은 쉘이 잰 아래 여백을 따라 움직인다.
  - 메뉴를 닫을 때 초점은 버튼이 아니라 화면 제목으로 돌아간다.
- 쉘 응답 전에는 웹 버튼을 그리지 않아 두 버튼이 겹쳐 보이지 않는다. 응답이 제한 시간을 넘기면 웹 버튼을 그린다.

## 다시 검토할 조건

- 실기기 VoiceOver에서 네이티브 「⋯」를 눌러 웹 메뉴로 초점이 들어가지 않으면, 쉘이 초점을 옮기는 bridge 기능을 더하거나 사진함은 웹 버튼으로 되돌린다.
- 디자이너가 iOS 플로팅 버튼 모양을 따로 정하면 그 기준으로 바꾼다.
- 안드로이드를 출시 대상에 넣으면 안드로이드의 유리 효과를 다시 검토한다.
