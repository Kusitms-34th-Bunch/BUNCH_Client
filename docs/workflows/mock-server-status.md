# 가짜 서버와 서버 연동 현황

가짜 서버(MSW, `apps/web/src/mocks`)로 연결한 화면과 아직 샘플 데이터로 둔 화면, 가짜 서버와 서버 명세의 차이를 모은다. 가짜 서버를 켜고 쓰는 방법은 [testing.md](./testing.md)의 「MSW 가짜 서버」를 본다.

## 연동 상태와 샘플로 남긴 부분

가짜 서버(MSW)는 개발에서만 켜고 운영은 실서버를 부른다. 아래 「가짜 서버로 연결한 것」의 화면은 가짜 서버로 연결했고, 「샘플로 남긴 부분」만 샘플 데이터로 두었다(2026-11-16 확인). 샘플로 둔 것은 화면이나 서버 구현이 없거나 저장 방식이 정해지지 않아서다. 값을 임의로 정한 것도 아래에 모았다.

### 가짜 서버로 연결한 것(명세 기준)

화면·기능별 API와 가짜 서버 동작은 영역별 문서로 나눴다(문서 길이, 2026-11-23).

- [mock-server-apis-bundle.md](mock-server-apis-bundle.md): 번들 작성(초안·픽·사진 구성·실시간 연결·제목 병합·presence)과 발행 번들(상세·수정·삭제·좋아요·댓글·신고·콕)의 가짜 서버 연동이다.
- [mock-server-apis-bunch.md](mock-server-apis-bunch.md): 번치 홈·전환·온보딩·프로필 편집·멤버·더보기·다른 번치·팔로우·차단·알림의 가짜 서버 연동이다.
- [mock-server-apis-my-feed.md](mock-server-apis-my-feed.md): 로그인·가입 상태, MY(프로필·알림 설정·푸시·탈퇴·추가 정보), 사진함, 피드·광고의 가짜 서버 연동이다.

### 샘플로 남긴 부분

| 화면      | 샘플인 것                                                                                     | 이유·연결 시점                             |
| --------- | --------------------------------------------------------------------------------------------- | ------------------------------------------ |
| 번들 작성 | 장소 검색 결과(샘플 장소 6곳, 웹 BFF `GET /api/places/search`를 가로채 카카오 호출 없이 응답) | 실제 카카오 호출은 실서버·키가 있어야 확인 |

### 임의로 정한 값

| 값                                | 정한 값                                                                                                                                                                | 위치                                    |
| --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------- |
| 번치 팔로워·팔로잉 수             | 가짜 DB의 팔로우 관계 수 + 관계 밖 수(캠핑러버 21·7, 책방산책 31·12)                                                                                                   | `src/mocks/db/seed.ts`                  |
| 번치 홈 Stage 규칙                | 명세 기준(발행본 0~~1=1, 2~~5=2, 6~9=3, 10개 이상=4)                                                                                                                   | `src/mocks/handlers/bunchHome.ts`       |
| 추천 번들 ID·묶음                 | 가짜 서버가 고정한 묶음 2개(ID 1·2, 서버 규칙 아님). 초안 생성에 없는 추천 ID를 보내면 실서버처럼(2026-11 확인, 200) 거절하지 않고 추천 연결 없이 만듦(제목 비어 있음) | `src/mocks/handlers/recommendations.ts` |
| 소속 ID·참여 시각                 | 회원 ID와 고정 시각                                                                                                                                                    | `src/mocks/handlers/bunchHome.ts`       |
| 피드 광고·사진 pick·좋아요 수     | 광고 내용은 고정 1개(「플로디스튜디오」, 콕·숨김만 가짜 DB), 상세의 사진 pick은 없음(가짜 DB에 없음). 좋아요 수는 차단 관계 번치의 좋아요도 셈                         | `src/mocks/handlers/feed.ts`            |
| 기존 발행 번들의 코멘트·공개 범위 | 「함께해서 즐거웠어요!」, 멤버 공개                                                                                                                                    | `src/mocks/db/seed.ts`                  |
| 사진 업로드 시각                  | 사진 ID로 만든 값(서버가 주지 않음)                                                                                                                                    | `features/photo-box/model/photos.ts`    |
| 번들 응답의 위치 ID               | 위치 작업(`locations/intents`)으로 추가한 줄은 발급한 번호를 유지하고, 시드의 위치는 배열 순서로 만든 번호                                                             | `src/mocks/handlers/bundles.ts`         |
| 번들 응답의 댓글 ID               | 배열 순서로 만든 번호(항목을 지우거나 옮기면 바뀜)                                                                                                                     | `src/mocks/handlers/bundles.ts`         |
| 번들 좋아요·댓글 수와 권한        | 번들 snapshot(`GET …/bundles/{id}`)의 소셜 값은 0·false 고정(실제 수는 피드·발행 상세에서 `likes.ts`·`comments.ts`가 셈), 권한은 명세 기준 발행본만 허용               | `src/mocks/handlers/bundles.ts`         |
| 안내 문구(기획 원문 없음)         | 최신 사진 목록 재조회 실패, 사진 구성 변경 중 업로드 막기, 저장 실패 안내 등                                                                                           | 각 feature `constants/messages.ts`      |
