## 목적과 범위

### 포함

- 내가 메인 관리자인 번치를 번치마다 `BunchAccordion`으로 보여 준다. 처음에는 모두 접혀 있다(설계서 4번, 탈퇴하기(6)).
- 번치 이미지는 번치가 설정한 대표 사진이고, 없으면 그 번치 타입의 기본 이미지(`default-bunch/type-1~4.svg`)다. 탈퇴 확인 응답에는 타입이 없어 소속 번치 목록(`GET /members/me/bunches`, 번치 홈이 30초 안에 받은 목록은 재사용)에서 찾고, 목록을 받지 못하거나 거기 없으면 타입 1이다. 사진이 없는 멤버 후보는 기본 프로필 이미지(`default-profile.svg`)다.
- 번치를 펼치면 「멤버」 아래에 넘겨받을 수 있는 멤버가 나온다. 번치마다 한 명만 고른다. 같은 번치에서 다른 멤버를 고르면 바뀌고, 다른 번치의 선택은 그대로다(5-1·5-2번).
- 본인은 후보에 넣지 않는다(4번). 공동 관리자는 역할 배지를 붙이고 이름 뒤에 「공동 관리자」를 낭독한다.
- 모든 번치의 새 관리자를 고르기 전에는 「다음」이 비활성이다. 누르면 권한을 넘기고 탈퇴 안내로 돌아간다(5-3번).
- 돌아온 탈퇴 안내에서 「다음」을 다시 누르면 남은 메인 관리자 번치로 다시 판단한다. 모두 넘겼으면 최종 탈퇴 확인으로 간다(`WithdrawalScreen.spec.md`).

### 범위 외

- 넘기기 전 확인 창과 완료 안내. 설계서에 없다.
- 멤버가 나뿐인 번치. 넘길 멤버가 없어 목록에서 빼고 탈퇴할 때 서버가 함께 삭제한다(기능명세서 7.6.3 로직 4). query가 후보 없는 번치를 거른다.

## Route와 접근

- Path·params·search: `/my/withdrawal/transfer`, 없음. 입구는 탈퇴 안내의 권한 이전 안내 창 「권한 넘기러 가기」.
- 접근 권한·guard: `(app)` 그룹 기준을 따른다. 추가한 guard는 없다. 넘길 번치가 없으면(직접 진입, 그사이 모두 넘어감) 토스트 없이 탈퇴 안내로 돌아간다. 탈퇴 안내에서 들어왔으면 확인 체크를 유지한다.
- Layout·navigation: page가 전환 경계(`data-ssgoi-transition="/my/withdrawal/transfer"`)를 두고, 탈퇴 안내와 미는 slide(`menuSubSlide`)로 오간다. 뒤로 가기는 `useBackOr(MY_PATHS.withdrawal)`이다. 완료 뒤에는 탈퇴 안내의 「권한 넘기러 가기」로 들어왔으면(`markTransferFromGuide`) 뒤로 가기로 돌아가고, 주소로 바로 들어왔으면 탈퇴 안내로 `replace`한다. 항상 `replace`하면 정상 흐름에서 탈퇴 안내가 기록에 두 번 남는다.

## 상태와 흐름

- 초기 진입: 넘길 번치를 받는 동안 전체 로딩과 낭독용 「관리자를 넘길 번치를 불러오는 중이에요」. 받으면 모든 번치 접힘, 선택 없음, 「다음」 비활성. 받지 못하면 탈퇴 안내로 돌아가 그 화면에서 오류 토스트를 보인다.
- 「다음」: 번치마다 `POST /bunches/{id}/owner-transfer`를 따로 보낸다(멱등 키, 받은 멤버 목록의 내 소속 ID·버전). 보내는 동안 「다음」은 `aria-busy`이고 다시 눌러도 보내지 않는다(disabled로 바꾸면 초점이 빠져 ref로 막음). 「관리자 권한을 넘기는 중이에요」를 낭독하고 누른 순간의 목록을 유지한다. 보내는 동안과 넘긴 뒤에는 멤버 선택을 잠가 화면의 새 관리자와 실제로 넘긴 사람이 달라지지 않게 한다.
- 모두 넘기면 탈퇴 안내로 돌아간다. 누른 뒤에는 「다음」을 막아 돌아가는 전환 중 두 번 되돌아가지 않게 한다.
- 하나라도 실패하면 머물러 오류 토스트를 띄운다. 넘긴 번치는 다시 받은 목록에서 빠지고, 남은 번치(새 버전)만 다시 고른다. 다시 받기가 실패해도 넘긴 번치는 먼저 목록에서 뺀다. 고른 멤버가 다시 받은 목록에 없으면 그 번치는 고르지 않은 것으로 센다.
- 성공·실패와 관계없이 넘길 번치 목록, 해당 번치 홈·멤버 목록, 번치 전환 목록을 다시 받는다.

## UI와 접근성

- Component mapping:

| Figma           | 값                                                  | 사용한 컴포넌트·토큰                           |
| --------------- | --------------------------------------------------- | ---------------------------------------------- |
| 헤더            | 뒤로 가기(`#BCBEC2`), 제목 없음                     | `Header` + `HeaderIconButton tone="subtle"`    |
| 목록 위치       | 헤더 아래 16, 좌우 16                               | `pt-s8 px-padding-p8`                          |
| 번치 카드       | `Bunch_Accordion_Status`, 카드 사이 6               | `BunchAccordion`, `gap-s3`                     |
| 펼친 안쪽       | 좌우 10, 「멤버」 Body-4-SemiBold `#969AA0`·좌우 10 | `px-padding-p5`, `typography-body-4-semi-bold` |
| 「멤버」과 목록 | 사이 8, 멤버 사이 2                                 | `mb-s4`, `gap-s1`                              |
| 멤버            | `Profile Radio Card`(공동 관리자 배지)              | `ProfileRadioCard`                             |
| 「다음」        | SolidButton 48                                      | `Button`(primary)                              |

- Semantic: 화면 제목은 Figma에 없어 낭독용 `h1`(「관리자 권한 넘기기」)만 둔다. 번치 이름은 `h2` 안의 펼침 버튼이다. 번치마다 멤버를 `fieldset`으로 묶고, `legend`는 보이는 「멤버」 앞에 번치 이름을 낭독용으로 붙인다(예: 「퇴근런클럽 멤버」).
- Keyboard·focus: 펼침 버튼과 라디오는 기본 탭 순서를 따른다. 같은 번치의 라디오는 같은 `name`이라 방향키로 옮긴다.
- 고른 뒤 접은 번치 카드: 새 관리자를 고른 번치는 접혔을 때 `BunchAccordion`의 선택 상태(연한 브랜드 배경·테두리, Figma `Bunch_Accordion_Status` `Status=Selected` `4821:87460`)로 보이고, 펼침 버튼 이름 뒤에 「새 관리자: {이름}」을 낭독한다.
- 「다음」 설명: 막힌 이유와 남은 번치 수를 낭독용 문구(「모든 번치에서 새 관리자를 골라 주세요. 2개 중 1개 골랐어요.」)로 `aria-describedby`에 연결한다. 접힌 카드의 선택 표시와 함께 전체 진행 상황을 알린다.
- Interaction: 펼침·접힘(Smart Animate / Ease out / 200ms)은 디자인 시스템 `BunchAccordion` 기본 동작이다.

## 확인할 항목

- 카드 사이 간격 (제안): Figma는 펼친 카드 아래 10, 접힌 카드 사이 6으로 다르다. 탈퇴하기(6)의 접힌 목록 기준인 6으로 맞췄다.
- 화면 제목 (제안): Figma에 제목이 없어 낭독용 제목만 두었다. 보이는 안내 문구가 필요한지 디자인에 확인한다.
- 이전 대상 범위 (결정): 기능명세서 7.6.3은 나를 뺀 다른 멤버 누구나 받을 수 있다고 적었다. 공동 관리자와 일반 멤버를 모두 후보로 둔다. 돌아온 뒤 확인 체크는 유지한다(7.6.1 로직 1).
- 고른 번치 모양 (디자인 확인): 1110판 7.6.3 상세 3은 배경·테두리를 연보라, 펼침 화살표도 보라로 적었다. 지금은 `BunchAccordion` Selected 상태를 따른다. 화살표 색이 Figma와 같은지 확인한다.
- 이전 처리 (1110판 7.6.3 로직 1~3): 넘기면 나는 일반 멤버, 공동 관리자였던 새 관리자는 관리자가 된다. 넘긴 번치 멤버에게 관리자 변경 알림을 보낸다. 서버 처리라 API를 연결할 때 확인한다.
- 버전 충돌 오류 코드 (백엔드 확인): Swagger에 없어 모든 실패를 같은 토스트로 보이고 목록을 다시 받는다. 가짜 서버는 `MOCK_MEMBERSHIP_VERSION`을 쓴다.
