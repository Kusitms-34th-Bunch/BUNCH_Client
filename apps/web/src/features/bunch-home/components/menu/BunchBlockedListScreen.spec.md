## 메타데이터

- Status: 목록, 차단 해제 확인 창·토스트, 빈 상태 구현. 데이터와 처리는 fixture다. 이슈 #178.

- 기능 spec: 기능명세서 5.7, `docs/specs/bunch-home.md`.

## 목적과 범위

### 포함

- 「차단된 번치 N개」와 차단한 번치 목록(프로필 이미지·이름, 오른쪽 「차단해제」). 다른 번치 프로필에서 차단한 번치는 맨 위에 더해진다(#196).
- 「차단해제」 → 확인 창 → 「해제하기」로 해제. 목록에서 바로 빼고 개수를 갱신한 뒤 「{번치} 번치를 차단 해제했어요.」 토스트(체크 아이콘).
- 차단한 번치가 없으면 안내 이미지 자리와 「아직 차단한 번치가 없어요」 / 「차단은 번치 멤버 모두에게 적용되며, 서로의 번들・프로필・댓글은 보이지 않아요.」. 별도 동작 없음.

### 범위 외(후속)

- 서버 처리와 실패 토스트: 차단 API 연결 때 한다. 지금은 메모리 저장소(`useBlockedBunches`)라 새로고침하면 fixture로 돌아간다.
- 빈 상태 안내 이미지: Figma 4331:59751의 SVG(130×109, `src/shared/assets/images/empty/blocked-list-empty.svg`)다. 이미지와 문구 16, 제목 16/24 500 `text-tertiary`, 설명 13/18 `text-quaternary`.
- 다른 번치 차단(다른 번치 프로필의 더보기, 단위 9).

## 역할

- 권한 표상 다른 번치 차단은 멤버 누구나, 차단 해제는 메인 관리자와 공동 관리자만 한다(기능명세 5.10.4·5.10.5). 일반 멤버는 「차단해제」 버튼 없이 목록만 본다(사용자 결정). 역할은 멤버 관리에서 바뀐 값(`useBunchMembers`)을 우선한다.
- 화면 표시용 판단이고, 서버가 요청 시점의 역할로 다시 판단해야 한다.

## 확인 창

- Figma(`2141:37877`)처럼 프로필 이미지·제목·설명 아래 버튼을 세로로 둔다(`ActionDialog`). 제목 「{번치} 차단을 해제할까요?」, 설명 「서로의 번들과 프로필을 볼 수 있어요. 팔로우는 자동으로 돌아오지 않아요.」, 버튼 「해제하기」·「취소」.
- Figma 확인 창의 「번치에서 내보내기」는 넣지 않았다. 차단은 번치 단위라 멤버를 내보내는 동작과 맞지 않는다(사용자 결정, 디자인 확인 필요).
- 설계서 설명은 `Profile - Side by Side`(두 버튼 가로)지만 Figma 화면의 세로 배치를 따랐다.

## Route와 접근

- 진입: 더보기 메뉴 「차단 목록」 링크(모든 역할). 메뉴 ↔ 차단 목록은 메뉴 하위 화면과 같은 미는 slide 300ms(화면설계서에 정의 없음). 탭 경로 밖이라 iOS 앱에서는 시스템 탭 바가 숨는다.
- 접근: 모든 역할이 들어오므로 redirect 가드는 두지 않는다(해제 버튼만 역할로 나눔).
- 뒤로 가기: 기록이 있으면 `router.back()`, 없으면 더보기 메뉴로 `replace`.
- 첫 hydration은 저장된 번치를 몰라 목록도 빈 상태도 그리지 않는다. 순간이라 로딩 표시는 두지 않았고, API를 붙여 대기가 길어지면 로딩 상태를 더한다.

## UI와 접근성

- Component mapping: `Header`(뒤로 가기), `ProfileListItem` + `Button` sm secondary(글자 `text-tertiary`, Figma SolidButton 32px), `ActionDialog`, `ProfileImage` 56px(확인 창 이미지).
- 간격(Figma `1873:33766`): 헤더 아래 12, 개수와 목록 사이 12, 행 사이 8. 빈 상태(`1873:33828`): 이미지와 문구 사이 18, 제목·설명 사이 6, 본문 세로 가운데보다 약 38 위(아래 여백 72로 맞춤).
- 목록은 `ul`/`li`. 「차단해제」 이름은 「{번치} 차단해제」. 헤더에 화면 이름이 없어 `sr-only` `h1`(「차단 목록」)을 둔다.
- 토스트는 확인 창이 다 닫힌 뒤 띄운다. 해제하면 「차단해제」 버튼이 사라지므로 초점을 「차단된 번치 N개」 줄로, 목록이 비면 빈 상태 제목으로 옮긴다.
