- Status: UI 구현됨(목록은 fixture, 개발 서버 Chrome 375폭 렌더로 Figma와 대조). API·이어 불러오기·당겨서 새로고침은 범위 밖. 실기기 전
- 기능명세: 피드 6.1(`docs/specs/feed.md` 구현 단위 1)
- 디자인 출처: Figma 피드 `4940:99466`(섹션 「피드」 `4940:100716`), 헤더 `4940:99533`, 구간 안내 `4940:101293`, 끝 안내 `4940:101966`

## 목적과 범위

### 포함

- 헤더: 로고(누르면 맨 위로), 알림(번치 알림 목록), 지금 번치 이미지(번치 탭). 지금 번치는 내 정보의 기본 번치(`myProfileQueryOptions`, 번치 홈과 같은 기준)
- 번들 카드(`FeedBundleCard`) 목록: 팔로우한 번치 구간 → 구간 안내(축하 로티와 양옆 선) → 공개 구간 → 끝 안내(체크 로티). 팔로우 구간이 비면 구간 안내 없이 공개 구간부터
- 경과 시간(`lib/elapsedTime.ts`): 「방금 전」·「N분 전」·「N시간 전」·7일까지 「N일 전」·8일부터 「YYYY년 M월 D일」. 브라우저에서만 계산한다(`useClientNow`, 서버 렌더·첫 hydration은 빈 글자). 서버와 브라우저의 시계·시간대가 달라 글자가 어긋나지 않게 하기 위함이며, 기준 시각은 페이지를 연 시각이라 오래 띄워 두면 갱신되지 않는다
- 카드에서 누르는 곳: 번치 → 지금 번치면 번치 탭, 아니면 다른 번치 프로필 / 사진 → 번들 상세 / 말풍선 → 번들 상세 댓글 영역 / 하트 → 좋아요(화면에서만 바꿈)
- 소속 번치가 없으면 헤더에 로고만, 공개 구간만, 좋아요는 「번치에 참여하면 할 수 있어요.」 토스트(6.1.7)

### 범위 외

- 서버 연동(구현 단위 10), 이어 불러오기(6.1.4 로직 3), 당겨서 새로고침, 다른 탭에 갔다 와도 스크롤 위치 유지, 번치 전환 때 다시 불러오기
- 안 읽은 알림 점: 번치 홈 헤더처럼 Figma가 정해지면 추가
- 좋아요 서버 반영·실패 되돌리기(구현 단위 3), 위치 → 콕하기 시트·참여 멤버 시트(구현 단위 7, 지금은 누를 수 없는 글자·이미지), 광고 카드(구현 단위 9)
- 번들 상세 화면(구현 단위 2): 지금은 사진·말풍선이 아직 없는 `/bundles/[bundleId]`로 간다

## 상태

- 지금 번치를 받기 전(첫 렌더)이나 내 정보 요청이 실패했을 때: 헤더 오른쪽은 알림만(번치 이미지 없음), 목록은 두 구간 모두 보임(번치가 있는 사람이 대부분이라 깜빡임을 줄임)
- 소속 번치 없음: 위 「포함」 마지막 항목
- 두 구간이 모두 비면 끝 안내만(fixture에는 없는 경우)

## 접근성

- 화면 제목 `h1`(「피드」, 화면에서는 숨김), 카드 제목은 `h2`, 목록은 구간마다 `ul`
- 로고 버튼 이름은 「BUNCH, 맨 위로」, 지금 번치 링크는 「{번치 이름} 번치 홈」
- 로티는 장식(`aria-hidden`), 안내 글자는 일반 문단. 동작 줄이기면 재생하지 않고 축하는 첫 장면, 체크는 마지막 장면(체크가 보이는 상태)
- 로고로 맨 위로 갈 때 동작 줄이기면 바로 이동. 초점은 고정 헤더의 로고 버튼에 남는다
- 헤더 누르는 영역: 로고 43px 높이, 알림 40px·번치 이미지 44px(사이 16px라 겹치지 않음)

## Styling과 의존성

- 카드 목록 좌우 16, 카드 사이 32(`gap-s14`), 위 16. 구간 안내 위아래 32, 선과 글자 사이 9(`gap-2.25`, 토큰 없음), 선은 `border-tertiary`. 끝 안내 위아래 40
- 로고는 Figma에서 받은 `shared/assets/images/logo/wordmark-dark.svg`(69×19)
- 로티는 안내가 처음 화면에 보일 때(`useInView`, IntersectionObserver) `LazyLottie`(`loop={false}`, 동작 줄이기 장면 `stillFrame`)로 `feedCaughtUp*.json`을 받아 한 번 재생. 스크롤해 다시 보일 때는 재생하지 않고, 피드에 다시 들어오면 다시 재생. 안내 글자(구간 안내는 양옆 선 포함)도 그때 0.233초 동안 투명 → 선명으로 나타난다(체크 모션의 투명도 구간과 같음, Figma에는 없지만 디자이너 확인). 글자는 처음부터 DOM에 있어 화면 낭독은 모션과 무관하고, 동작 줄이기면 모션 없이 보인다

## 확인할 항목

- 구간·끝 안내 글자 `text-quinary`(#BCBEC2)는 흰 바탕에서 약 1.9:1이다(Figma 값). 상태를 알리는 글자라 진한 회색(`text-quaternary`·`text-tertiary`)으로 바꿀지 디자이너 확인
- 동작 줄이기에서 체크 로티가 마지막 장면으로 그려지는지는 실제 렌더로 확인하지 않았다(테스트는 로티를 대체함)
- 소속 번치가 없는 사람은 첫 렌더에 팔로우 구간과 알림이 잠깐 보였다가 사라진다(내 정보 응답 전). 받은 적이 있으면 캐시로 바로 맞음

- 「N일 전」은 24시간 단위로 셌다(어제 밤 글이 오늘 아침에 「N시간 전」). 달력 날짜 기준인지 기획 확인
