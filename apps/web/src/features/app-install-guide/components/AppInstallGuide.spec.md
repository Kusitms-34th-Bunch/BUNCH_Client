# 화면: 앱 설치 안내(웹으로 들어왔을 때)

## 메타데이터

- Route: 별도 route 없음. `(app)` 그룹의 모든 화면이 브라우저에서 열리면 `app/(app)/layout.tsx`의 `AppOnlyGate`가 화면 대신 이 안내를 그린다.
- Status: UI·등장 모션·PC 배경 반복 구현(#566). 운영 빌드(가짜 서버 끔)를 1440×900·2000×1000·1280×720·375×812로 Figma와 비교했다. 실기기 Safari·VoiceOver는 미검증.
- 디자인 출처: Figma 「웹으로 접속했을때 화면」(node `8038:187763`), 모바일 `8038:185708`, PC `8038:185798`, PC 모션 스펙 `8038:187330`, 모바일 모션·레이아웃 스펙 `8038:187545`.

## 목적과 범위

### 포함

- 브라우저(모바일·PC, 홈 화면에 추가한 웹 앱 포함)로 들어온 사람에게 앱이 있다는 것과 설치 경로를 알린다. 로고, 제목 「함께한 순간은 휴대폰에서 모여요」, 설명, 휴대폰 목업, 「iOS 앱 설치하기」(App Store 링크, 같은 탭).
- 1024px 미만은 모바일 배치(위에서부터 쌓고 버튼은 아래 고정), 1024px 이상은 PC 배치(왼쪽 글·버튼, 오른쪽 목업, 아래 배경 반복).

### 범위 외

- Android 설치 버튼. 출시 전이라 두지 않는다(출시 뒤 추가).
- 앱 안(쉘)과 로컬 개발 서버·가짜 서버 빌드. 이 안내가 나오지 않는다(`docs/architecture/routing-and-access.md` 「앱 안에서만 여는 화면」).
- 초대 링크 진입(`/invite/[token]`). `(app)` 밖이라 브라우저에서도 그대로 열린다.

## 상태와 흐름

- 서버 렌더·hydration 동안은 쉘 여부를 몰라 `AuthGate`의 로딩(1초 넘으면 보이는 덮개)을 그리고, hydration 직후 렌더에서 안내로 바뀐다. 이때 등장 애니메이션이 시작된다.
- 브라우저 탭 제목은 원래 route의 제목(예: 「피드」) 그대로다. 쉘 여부를 서버가 몰라 metadata로 바꿀 수 없다.
- 「iOS 앱 설치하기」는 `APP_STORE_URL`로 가는 링크다. iPhone이 아닌 기기에서도 같은 링크(App Store 웹 페이지)로 간다.

## 모션

- 등장(한 번): 위에서부터 차례로 아래에서 올라오며 나타난다. 이동 `cubic-bezier(0.25, 0.1, 0.25, 1)`, 투명도 `cubic-bezier(0.4, 0, 0.2, 1)`, delay 전에는 투명하고 끝나면 유지(`installGuideRise.module.css`, CSS만이라 JS 없이 재생).

| 요소 | delay | 모바일 이동·시간 | PC 이동·시간 |
| ---- | ----- | ---------------- | ------------ |
| 로고 | 0.20s | 16px·1.5s        | 14px·1.4s    |
| 제목 | 0.38s | 16px·1.5s        | 16px·1.5s    |
| 설명 | 0.56s | 16px·1.5s        | 14px·1.4s    |
| 목업 | 0.60s | 16px·1.5s        | 24px·1.8s    |
| 버튼 | 0.74s | 16px·1.5s        | 14px·1.4s    |

- PC 배경(12초 반복, 페이지가 열리면 바로 시작): 파스텔 타원 4개(`primitive-bunch-100`·`green-50`·`orange-100`·`pink-100`, blur 75·100px)가 sin 식으로 오가며 커지고 흐려진다. 흰 점 396개(10px 격자, 지름 8px)는 8묶음으로 나뉘어 묶음마다 12초에 3번 흐려졌다 돌아오고, 1·3·5·7묶음은 흐려진 순간 한 칸 옮겼다가 세 번째에 제자리로 온다. 값은 Figma 스펙 표 그대로(`lib/backgroundMotion.ts`), 점 위치는 Figma 레이어 좌표 그대로(`lib/dotGroups.ts`).
- 타원은 transform·opacity만 바꾸고, 점은 canvas 하나에 그린다. 탭이 숨으면 멈췄다가 이어서 재생하고, 1024px 미만(배경이 숨는 배치)에서는 반복을 돌리지 않는다.
- 1440px보다 넓은 창은 배경을 창 폭까지 가로로 늘리고(점도 같은 비율로 커짐), 좁은 창은 가운데 기준으로 자른다.
- 동작 줄이기: 등장은 이동 없이 투명도만 0.3초, 배경은 처음 모습으로 정지.

## 접근성

- 제목은 `h1` 하나, 로고는 `alt="BUNCH"`, 목업은 장식(`alt=""`), 배경은 `aria-hidden`.
- 모바일·PC 설명 문구가 달라 둘 다 두고 배치에 맞지 않는 쪽은 `display: none`으로 숨긴다(읽기 도구도 하나만 읽음).
