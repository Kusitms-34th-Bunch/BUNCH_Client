# 페이지: 픽하기(`/bunch/drafts/[draftId]/pick`)

## 메타데이터

- Route: `apps/web/src/app/(app)/bunch/drafts/[draftId]/pick/page.tsx`. layout의 `DraftProvider`로 작성 화면과 초안 상태를 함께 본다.
- Status: 구현됨(개발 서버 Chrome 측정, 실기기 전). 서버 필드가 없어 픽은 초안을 보는 동안만 유지한다(나가거나 새로고침하면 사라짐).
- 디자인 출처: Figma `픽하기_4명 픽했을때` `5699:103678`, `픽하기_8명 픽했을때` `5699:103571`, `픽하기_픽했을때` `5699:103643`, `픽하기_모션` `5699:103708`.

## 목적과 범위

### 포함

- 안내 문구, 제목, 사진 가로 넘김(`BundlePickPhoto`), 픽 버튼, 픽한 인원과 칩.
- 버튼은 픽 전 「이 사진 픽하기」(`brandSubtle`), 픽 후 「사진을 픽했어요」(`brand`)다. 다시 누르면 취소한다.
- 칩은 내 이름이 맨 앞에 브랜드색이다. 픽한 사람이 없으면 인원과 칩을 숨긴다.
- 참여 멤버가 아니면 누를 때 「참여 멤버만 편집할 수 있어요」 토스트만 띄운다.

### 범위 외

- 글린트 입자(`Pick Glint`, `Mini Core Glints`, `Spark`).
- 다른 멤버가 사진을 지웠을 때의 「삭제된 사진이에요」 창(`5699:103606`). 서버 실시간 반영이 생길 때 추가한다.
- 서버 저장.

## Route와 접근

- 작성 화면 사진 줄의 「픽하기」 링크로 들어온다. 전환은 작성 화면과 같은 슬라이드(300ms)다.
- 없는 초안은 작성 화면과 같이 안내 후 번치 홈으로 간다. 직접 주소로 들어와 기록이 없으면 뒤로가기는 작성 화면이다.
- 검색에서 제외한다.

## 모션

- Figma 타임라인은 시연용으로 3.4초를 반복한다. 탭 뒤 구간만 한 번 재생하고 값은 그대로 쓴다.
- 버튼 0.96, 사진 0.985와 0.99 맥박(1050ms), 어두운 막, 1250ms 뒤 인원 글자와 내 칩 등장, 다른 칩은 1070ms 뒤 옆으로 이동한다(한 줄 4개까지만).
- 동작 줄이기면 재생하지 않는다.

## 접근성

- 사진 목록은 초점을 받는 「픽할 사진」 묶음이라 방향키로 넘긴다. 위치는 `role="status"`로 읽는다.
- 픽 상태는 버튼 글자와 `role="status"`(「4장 중 1번째 사진, 사진을 픽했어요」)로 알린다.

## 확인할 항목

- 한 사람이 여러 장을 픽할 수 있는지, 다시 눌러 취소하는지는 Figma에 없어 정했다(기획 확인).
- 안내 문구는 업로드 뒤 누가 픽했는지 보인다고 하지만 Figma는 업로드 전에도 칩을 보인다. Figma대로 했다.
- 인원·안내 글자 `text-quaternary`(`#969AA0`)는 흰 바탕에서 약 2.8:1이다(Figma 값).

## 검증

- 단위 테스트: 픽 전 버튼과 호출, 칩 순서와 인원, 참여 멤버가 아닐 때 안내.
- 개발 서버 Chrome 측정: 제목 22px, 카드 295×396·radius 6, 카드 사이 10, 버튼과 카드 사이 10, 버튼 높이 40, 인원 위 32, 칩 높이 29. 누르면 모션 5개가 재생되고 약 2초 뒤 0개로 끝난다.
