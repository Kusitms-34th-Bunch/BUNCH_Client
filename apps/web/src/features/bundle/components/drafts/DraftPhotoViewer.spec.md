# 페이지: 번들 사진 크게 보기

## 메타데이터

- Route: `/bunch/drafts/[draftId]/photos/[photoId]/viewer`(`apps/web/src/app/(app)/bunch/drafts/[draftId]/photos/[photoId]/viewer/page.tsx`). 작성 화면과 같은 `layout.tsx`의 `DraftProvider`가 초안 상태를 들고 있어 화면을 오가도 같은 초안을 본다.
- Status: 크게 보기, 사진 빼기(⋯의 「삭제」), 저장(목 지연)을 구현했다. 사진별 캡션과 캡션 화면은 서버·기능명세에서 없어져 제거했다(#354).
- 디자인 출처: 크게 보기 Figma `1782:32882`·`1782:32912`, 삭제 모달 `2082:49108`·`2082:49246`·`2091:61896`·`4850:62115`. 이슈 #173.
- 기능 spec: `docs/specs/bundle-create.md`의 4.3.4~4.3.6.

## 목적과 범위

### 포함

- 크게 보기: 헤더(뒤로가기, 촬영 날짜, ⋯), 원본 비율 사진, 올린 멤버 배지, 좌우로 번들 순서대로 넘김. 배지와 헤더 날짜는 번들에 담은 사람이 아니라 사진함 원본(`sourcePhotoId`)의 올린 멤버(함께 올린 사진은 여러 명)와 촬영 날짜다. 사진함 데이터를 받는 동안과 원본이 없는 사진은 배지·날짜를 비우고(원본이 없으면 「날짜 미확인」), 사진 보기와 삭제는 기다리지 않는다.
- 사진 빼기(⋯의 「삭제」): 2장 이상이면 항상 「사진을 삭제할까요?」 확인(픽이 있으면 「멤버들이 픽한 사진이에요」/「사진을 삭제하면 픽도 함께 삭제되며, 복구할 수 없어요.」, 「삭제하기」 왼쪽·「취소」 오른쪽, Figma `4850:62115`) 뒤에 뺀다. 1장이면 「사진을 삭제할 수 없어요」 안내만 연다. Swiper가 슬라이드를 옮긴다.
- 「저장」은 실제 앨범 저장 없이 목 지연(0.9초)만 둔다. 그동안 화면 전체에 딤과 로딩 점(`PageLoading`)을 보이고 ⋯·사진 영역은 막으며, 끝나면 「이미지 저장이 완료되었어요.」 토스트를 아래에 띄운다(화면설계서 5번).
- 참여 멤버가 아니면 보기만 한다.

### 범위 외

- 서버 연동(순서 저장, 사진 삭제, 앨범 저장), 다른 멤버의 실시간 순서 반영, 보던 사진이 사라질 때의 실시간 처리.

## Route와 접근

- `(app)` route이며 `robots: noindex`다. 초안 id는 layout에서, 사진 id는 page에서 형식을 검증한다(`parseDraftId`·`parsePhotoId`). 없는 초안은 「삭제된 번들이에요」 토스트 뒤 번치 홈으로, 주소의 사진이 처음부터 초안에 없으면 「사진함에서 삭제된 사진이에요.」 토스트 뒤 작성 화면으로 이동한다(`replace`). 초안이 처음 준비되는 때 한 번만 판단하므로 화면을 보는 동안 그 사진을 빼도 쫓겨나지 않는다.
- 진입은 작성 화면의 사진 썸네일(`push`)이다. 사진을 넘길 때마다 `history.replaceState`로 주소의 사진 id만 바꿔 새로고침·공유가 보던 사진을 가리키게 한다. route의 사진 id는 처음 진입한 값으로 남으므로 보던 사진 id를 history 항목 상태에도 적어 두고(`usePhotoAddress`), 돌아오면 그 값을 먼저 쓴다. 적어 둔 사진이 초안에 없거나 형식이 틀리면 주소의 사진으로 연다.
- 뒤로 가기는 이전 기록이 있으면 `back`, 없으면 작성 화면으로 `replace`한다.

## UI와 접근성

- 사용 컴포넌트: `Header`·`HeaderIconButton`(`PageShell`), 확인 창 `ConfirmDialog`·`Dialog`, photo-box의 `PhotoDetailSlide`·`PhotoDetailHeader` 계열.
- 현재 사진 위치는 `role="status"`(「N장 중 M번째 사진」)로 알리고, 포커스가 있을 때만 보이는 이전·다음·확대 버튼을 둔다(기록 015).
- 사진을 빼면 같은 자리에 온 사진으로 초점이 가고 「사진을 뺐어요. N장이 남았어요.」를 낭독한다.
